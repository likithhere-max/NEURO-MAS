# NEURO-MAS — Agent Capability Matrix (Deliverable 2)

Statuses: **IMPLEMENTED** (code exists and behaves as described) · **VERIFIED** (the computation was
checked against an independent hand calculation or simulation) · **NOT FULLY VALIDATED** · **EXPERIMENTAL**
· **BLOCKED** · **NOT IMPLEMENTED**. "Verified" never implies clinical validity.

The spec's eight functional roles map onto the repo's ten registered agents as follows.

## Autonomy / safety policy (all agents)
Actions are proposed → checked by `core/safety.py` (autonomy level, confidence, data quality, disagreement) → delivered only if a provider confirms. With no provider configured, **no action is ever reported as executed.**
